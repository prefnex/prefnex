## About Prefnex

**Prefnex is an independent software venture founded and led by Ahmed Elkady, a senior software developer focused on building, shipping, and operating real-world software systems.**

We work across the full software lifecycle — from architecture and backend engineering to automation, data processing, deployment, and ongoing operations.

Our focus is not simply writing code. It is building systems that solve real problems, handle real workloads, and remain maintainable as they grow.

We build and operate software across:

- **Web platforms & SaaS** — production-ready applications and business platforms.
- **Automation & integrations** — bots, APIs, messaging workflows, and connected services.
- **Data engineering** — high-volume data collection, processing pipelines, and storage systems.
- **Backend infrastructure** — job queues, caching, database optimization, and scalable services.
- **Developer tooling** — practical tools that improve workflows and solve engineering problems.

## Selected Projects

### Radar — Smart Shopping Assistant

A smart shopping and price-tracking product focused on helping shoppers discover deals and make better purchasing decisions.

- Product price tracking and price history.
- Deal discovery and product recommendations.
- Shopping workflows for regional e-commerce platforms.
- Browser extension experiences and deal distribution.

**Focus:** E-commerce · Price Intelligence · Browser Extensions · Automation

### StoresScraperGo

A Go-based data collection system built to process product data across e-commerce sources.

- Concurrent scraping and distributed workload execution.
- Data processing and database integration.
- Worker-based job execution.
- Performance-oriented backend engineering.

**Focus:** Go · Data Pipelines · Concurrency · PostgreSQL

### Evolution GO

A Go-based project focused on messaging and service integrations.

- API-driven application workflows.
- Service operation and process management.
- Integration-oriented backend development.

**Focus:** Go · APIs · Integrations · Production Operations

## How We Engineer

**Built for production, not just the demo.**

- **End-to-end ownership:** Consider architecture, implementation, deployment, and operation together.
- **Performance with purpose:** Measure bottlenecks and optimize where it makes a meaningful difference.
- **Maintainable systems:** Prefer clear boundaries, predictable behavior, and code that can evolve.
- **Automation first:** Reduce repetitive work and make operational processes reproducible.
- **Real-world trade-offs:** Balance speed, reliability, complexity, and cost instead of chasing trends.
